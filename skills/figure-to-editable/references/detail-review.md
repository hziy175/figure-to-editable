# 细节复核

## 选取要检查的区域

先整页检查面板比例、视觉重心、留白、阅读顺序。再检查高风险局部：密集节点图、规则色块、重叠图层、上下标、小字和长误差线。用户点名的区域必须逐一对照，不以整页缩略图替代。

并排图使用相同源图范围和等比例缩放。推荐显示到可辨认单元格和连接端点的尺寸；不要把原图放大和重建图缩小后声称相同。比较裁剪属于核查材料，不自动将截图加入最终 PPT。

| 部件 | 对照内容 |
| --- | --- |
| 节点图 | 节点数、中心位置、邻接边、是否确实存在外围边；不凭“常见画法”补边 |
| 特征条/矩阵 | 行列数、格宽、每格颜色次序、边线厚度；不要用泛化渐变替代原图色块分布 |
| 多层平面 | 每层角点、可见轮廓、层间距、前后顺序、透明度以及交叠区域颜色 |
| 球体与圆环 | 球半径、高光位置、轮廓、圆环半径和虚线节奏；预览器不支持渐变时先诊断渲染 |
| 公式与文字 | 原始拼写、大小写、换行、上下标、字体替代后的实际宽度；避免上下标重复缩小 |
| 曲线及箭头 | 起止对象、方向、折点、经过区域、端点间隙和前后遮挡关系 |
| 局部图片 | 裁剪轮廓完整，未混入文字/箭头/面板边框；不能删掉属于主体的游离组成部分 |

## 记录差异

使用简短、可执行的记录：对象名、源图证据、当前差异、拟修改属性、修后结果。示例：`FIG_A_feature_seq` 源图四格，当前三格；增加第四格并逐格采样颜色。

检查发现应分开：

- `structural_findings`：缺少对象、文字错误、端点偏差、文件/指纹不一致。
- `visual_findings`：错误拓扑、明显的密度或比例差异、失真的细节、视觉碰撞。
- `limitations`：可接受且已披露的字体替代、位图精度、渲染器差异。不能把未修复的错误塞进 limitations 来冒充通过。

记录每个区域 `pass` 或 `needs_revision` 及证据路径。不把相同对象数量或自己的满意程度转换成 0.95 等无依据分数。只有实际对照后才填写 pass。
