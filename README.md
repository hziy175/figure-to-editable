# 图像转可编辑 · figure-to-editable

Codex 技能，将参考图片中的科研架构图、流程图和统计图重建为可编辑 PowerPoint，并支持根据局部截图继续修正。

## 适用场景

- 将论文模型架构图、流程图或技术示意图转为可编辑 PPT。
- 保留原图布局、文字、箭头和连接关系。
- 重建统计图的坐标轴、数据点、误差线和标签。
- 按用户指出的局部差异，修正节点、连线、色块、叠层及公式。

本技能侧重参考图还原；单纯图片变清晰或由论文生成整套演示文稿，应使用对应工作流程。

## 安装

向支持技能安装器的 Codex 输入：

```text
使用 $skill-installer 安装以下 GitHub 目录中的技能：
https://github.com/hziy175/figure-to-editable/tree/main/skills/figure-to-editable
```

私有仓库需要安装环境已通过 GitHub 身份验证，并且账号具有访问权限。

也可以将本文件所在的整个 `figure-to-editable` 文件夹复制到客户端实际使用的个人技能目录，保持子目录完整。安装后选择「图像转可编辑」，或使用 `$figure-to-editable` 调用。

## 使用方法

### 图片转 PPT

附上参考图片后输入：

```text
使用 $figure-to-editable 将这张图转为可编辑 PPT。
保持原图布局、文字、配色和连接关系，提供最终 PPT 与预览，并说明哪些元素可以编辑。
```

### 修正局部细节

附上原图、已有 PPT 和需要修正的局部截图后输入：

```text
使用 $figure-to-editable 对照原图修正这些局部差异。
检查同类部件是否存在相同问题，保留其他区域和上一版本，输出更新后的 PPT 与预览。
```

### 重建统计图

```text
使用 $figure-to-editable 重建这张统计图，保留坐标轴、数据点、误差线和全部标签。
如果只有截图，请说明数值来自图像估读；如果提供了原始数据，请优先使用数据，并说明是否支持在 PPT 中编辑底层数值。
```

## 提供哪些材料

| 材料 | 用途 |
| --- | --- |
| 清晰的完整原图 | 确认布局、文字及连接关系 |
| 局部放大图 | 核对细小文字、色块、节点及线段 |
| 已有 PPT | 在现有结果上继续修改 |
| 原始数据或矢量文件（如有） | 提高统计数值和几何还原精度 |

可同时说明目标页面比例、字体要求，以及需要编辑图形外观还是底层数据。默认一张参考图对应一页，保留原有布局。

## 交付内容

- 可编辑的 `.pptx` 文件。
- 最终保存状态对应的预览图。
- 简短的编辑范围和已知限制说明。
- 需要核对局部差异时，提供并排对照图。

## 可编辑范围

| 对象 | 编辑能力 |
| --- | --- |
| 原生文本框 | 修改文字、字体、颜色和位置 |
| 原生图形、点和连线 | 修改形状、样式和位置 |
| 原生图表 | 在生成工具支持时修改底层数据 |
| 复杂纹理或蛋白质表面等局部图片 | 整体移动、缩放或替换；内部像素不可逐元素编辑 |

只有截图时，统计点位和区间属于图像估读，不能当作原始实验数据。由原生点线组成的统计图，也不等同于绑定数据表的原生图表。

## 环境要求

本技能提供重建规范和检查工具，需要运行环境具备可用的 PowerPoint 连接、OfficeCLI 或受支持的幻灯片生成库。审计脚本使用 Python 标准库。预览需要相应渲染工具，结果中应说明实际采用的生成与验证方式。

## 常见问题

**为什么有的内容仍是图片？**
复杂分子表面、照片或显微纹理可能需要保留独立局部图片，以保证外观与科学含义。交付时应明确这些区域的编辑范围。

**为什么 README.md 和 SKILL.md 都要保留？**
README.md 是给使用者看的安装与使用说明；SKILL.md 是给 Codex 读取的执行规范。

**为什么必须保留子目录？**
技能依赖相对路径读取说明和审计脚本。把所有文件放到同一层会使这些路径失效。
